# Contributing to PanzaScope

Thank you for your interest in contributing to PanzaScope! We welcome community involvement to help improve the core engine. To ensure the project remains consistent and maintainable, please follow these guidelines:

### How to Contribute
1. **Open an Issue**: Before starting any work, please open an issue to discuss your proposed changes or new features. This helps us align with the project's roadmap.
2. **Fork & Branch**: Fork the repository and create a dedicated branch for your work (e.g., `git checkout -b feature/your-feature-name`).
3. **Submit a Pull Request**: When you're ready, submit a Pull Request. Please provide a clear and concise description of the changes you've made.

### Project Vision
PanzaScope serves as the open-source logic core for the broader **Panza Labs** ecosystem. 
* We welcome contributions that improve stability, performance, and core analytical capabilities.
* Please note that architectural decisions regarding Unity Editor integration and proprietary UI Toolkit features remain under the exclusive control of Panza Labs.

### Code of Conduct
We maintain a respectful and collaborative environment. All contributors are expected to uphold these values. Every contribution must comply with the terms defined in the [LICENSE](LICENSE) file (MIT License).

### Questions?
If you have any questions or need clarification on the project's direction, feel free to reach out via the GitHub Discussions or the issues section.
